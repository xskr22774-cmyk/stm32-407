# STM32F407 学习资料与例程

本仓库用于学习 STM32F407，**以 HAL 库为主要学习方向**。根目录中的 HAL 库配套例程作为主要实践资料，新增的 [F407PPT](./F407PPT/) 作为标准外设库（标准库，SPL）的补充学习资料。

## 学习定位

我的主要学习目标是掌握 HAL 库，能够理解并完成外设配置、驱动编写和实际项目开发。同时，我也会学习标准库课件，帮助理解 STM32 的外设原理、寄存器配置思路，以及不同库对硬件操作的封装方式。

标准库资料作为补充，与 HAL 库例程按相同外设主题对照学习；不要求先把整套标准库学完，再开始 HAL 库。

## 建议的学习方式

1. 以 HAL 库例程为主，逐个学习 GPIO、时钟、中断、串口、定时器等外设。
2. 遇到不理解的外设原理或配置步骤时，查阅标准库 PPT 中对应的章节。
3. 对照两套库的初始化、数据收发和中断处理过程，理解它们如何操作同一类硬件资源。
4. 将理解应用到 HAL 库工程中，通过修改例程和实际调试验证。

## HAL 库与标准库的区别

HAL 库和标准库是不同的软件接口体系，函数命名、数据结构、初始化流程和中断处理方式有所不同。**标准库课件中的示例代码不能直接复制到 HAL 工程中混用。**

学习时可以借鉴外设原理和配置思路，但实现代码需要按照 HAL 库的接口和工程结构重新组织，并核对开发板型号、引脚连接、时钟配置及所使用的库版本。
